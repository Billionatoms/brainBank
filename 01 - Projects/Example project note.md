# Example project note

`01 - Projects/` holds **time-bounded work with a deliverable and an end date**.

Give each project its own subfolder as it grows. Project notes link freely to
permanent notes; permanent notes should not link back, since they outlive any
one project. Finished projects move to `07 - Archives/`.
