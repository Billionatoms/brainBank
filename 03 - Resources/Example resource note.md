# Example resource note

`03 - Resources/` holds notes **about a source**: a paper, a talk, a chapter, a
link worth keeping. Put the URL or citation in `source:`.

If you use Zotero with Better BibTeX, keeping the citation key as the filename
(`@author2024title.md`) makes `[[@author2024title]]` links line up with your
library.
