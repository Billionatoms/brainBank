# Example permanent note

A **permanent note** holds one evergreen idea in your own words, written so it
still makes sense in three years.

Filenames are descriptive sentence-case phrases, often question-style:
`What is cross-entropy loss.md`. No date prefixes, no kebab-case.

Inline maths works out of the box: $E = mc^2$. So do blocks:

$$
\sigma = \frac{N}{\mathcal{L} \cdot \epsilon}
$$

> [!NOTE]
> Callouts come from Obsidian plus the Admonition plugin.

Link by exact basename, no folder path and no `.md`: [[Example fleeting note]].
Then index the note from a map, so it is not orphaned: [[MOC - Example Topic]].
